## 🎬 Movies Database Schema

The `Movies` table contains the following columns:

| Column Name | Data Type |
|---|---|
| movie_id | INT (Primary Key) |
| title | VARCHAR(100) |
| release_year | INT |
| genre | VARCHAR(50) |
| language | VARCHAR(30) |
| duration_minutes | INT |
| rating | DECIMAL(3,1) |

**SQL Query:**
```sql
SELECT * FROM Movies;
```

This query displays all records from the Movies table.
