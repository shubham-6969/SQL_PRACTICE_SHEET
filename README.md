# 🎬 MovieDB SQL Practice (Q1–Q80)

## 📌 About the Project

This repository contains my SQL practice questions and solutions using a custom **MovieDB** database. I created a `Movies` table and solved 80 SQL questions to strengthen my understanding of SQL queries and data analysis concepts.

This project is part of my journey toward becoming a **Data Analyst**.

## 🎯 Objectives

- Strengthen SQL fundamentals through hands-on practice.
- Understand how to filter, sort, and retrieve data.
- Practice aggregate functions and grouped data analysis.
- Improve logical thinking and query-writing skills.
- Build a foundation for real-world data analytics projects.

## 🛠️ Tools & Technologies

- **SQL Server**
- **SQL Server Management Studio (SSMS)**
- **Git & GitHub**

## 📚 Topics Covered

- `SELECT` and `DISTINCT`
- `WHERE` and comparison operators
- Logical operators: `AND`, `OR`
- `LIKE`, `IN`, `NOT IN`, `BETWEEN`
- `ORDER BY` and `TOP`
- Aggregate functions: `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`
- `GROUP BY` and `HAVING`
- Column aliases using `AS`
- Combining multiple filtering conditions

## 🗃️ Database Schema

The project uses a `Movies` table with the following columns:

| Column | Description |
|---|---|
| `movie_id` | Unique movie identifier |
| `title` | Movie title |
| `release_year` | Year of release |
| `genre` | Movie genre |
| `language` | Movie language |
| `duration_minutes` | Movie duration in minutes |
| `rating` | Movie rating |
